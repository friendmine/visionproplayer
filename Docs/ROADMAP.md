# 观影体验开发规划

按以下顺序交付，每项用实际观影流程验收。

1. [x] **影院字幕与音轨**（2026-11-05 真机佩戴验收通过）。在影院切换配音与字幕，设置外挂字幕字号和位置，返回窗口后继续播放并保留选择。
2. [x] **进度条画面预览**（2026-11-05 控制面板显示修订验收通过）。拖动时在进度条下方显示目标时间的画面，松手后跳转并恢复按钮。窗口和影院都可用，立体片只预览单眼。42 项基础短测及当前片源双引擎共 6 次取帧通过，用户确认当前影片在窗口和影院的预览、跳转与操作均正常。
3. [x] **AI 立体观影预设**（2026-11-05 真机 37 项短测及佩戴验收通过）。提供「自然」「突出前景」「自定义」，可将当前效果设为新影片的默认值。新加入影片保存默认参数快照，开启 AI 立体后生效；已有影片沿用自己的设置。用户确认窗口、影院、保存默认值及新旧影片设置均正常。
4. [x] **VLC 的 AI 立体偶发卡顿**（2026-11-05 真机短测及佩戴验收通过）。同片对照定位到 VLC 输出等待；本地 AI 播放改用共同的系统单调时钟，运动样片重复短测均未再出现超过 50 ms 的提交间隔。运动/H.265 正式版共 34 项回归短测通过；用户确认原问题影片在窗口和影院中卡顿改善，声音、人体比例和边缘均正常。保留旧时钟 Debug 对照和原始阶段记录。

5. [x] **完整记住播放偏好**（2026-11-06 真机 39 项短测及全部佩戴验收通过，版本 `0.81ok`）。逐片保存音轨、内嵌/外挂字幕及关闭状态，跨重开、引擎切换和影院会话恢复；缺失或暂不支持的轨道保留原意并提示，诊断样片不污染片库设置。
