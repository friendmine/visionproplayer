# 观影体验开发规划

按以下顺序交付，每项用实际观影流程验收。

1. [x] **影院字幕与音轨**（2026-11-05 真机佩戴验收通过）。在影院切换配音与字幕，设置外挂字幕字号和位置，返回窗口后继续播放并保留选择。
2. [x] **进度条画面预览**（2026-11-05 控制面板显示修订验收通过）。拖动时在进度条下方显示目标时间的画面，松手后跳转并恢复按钮。窗口和影院都可用，立体片只预览单眼。42 项基础短测及当前片源双引擎共 6 次取帧通过，用户确认当前影片在窗口和影院的预览、跳转与操作均正常。
3. [ ] **AI 立体观影预设**。提供「自然」「突出前景」「自定义」，可将当前效果设为新影片的默认值。已单独调过的影片优先使用自己的设置。
4. [ ] **VLC 的 AI 立体偶发卡顿**。在同一运动片段记录解码、深度估计和显示提交耗时，定位长帧间隔，再比较改动前后的长帧次数、音画同步和人体比例。
